## Downloaded and system components

- Rust dependencies are resolved by `Cargo.lock`; each crate retains its own license. Inspect full target-specific dependency metadata with `cargo metadata --locked --format-version 1`. The root license is not a complete license inventory.
- `scripts/setup-pdfium.cjs` downloads a hash-pinned PDFium release from [pdfium-binaries](https://github.com/bblanchon/pdfium-binaries). PDFium and its included third-party notices are collected and embedded; Menu > Licenses displays the prepared notices. Downloaded binaries and notices remain generated build assets, not checked-in source.
- Linux packaging collects GTK/GLib, WebKitGTK, GStreamer/plugins, OCR libraries, Tesseract language models and DejaVu fonts. Their individual licenses apply; keep the applicable package notices and source/relinking obligations when distributing binaries. The effective media/plugin license set depends on the build distribution. The AppImage pipeline's existing notices are not a complete distribution compliance certification.
- WebView2 Runtime, Windows OCR and Windows fonts are system components, not redistributed in this source archive. Microsoft terms apply.
- DeepL and Microsoft speech are external services with independent terms. Open-source code does not grant access rights to those services, voices or models.

A public binary release needs its own complete notice/source inventory for the exact files bundled. The prepared GitHub archive contains source only and makes no claim of a completed binary-distribution license audit.
